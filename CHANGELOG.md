# Changelog

## v1.0.0 — Initial Release

### Features
- Google Sign-In via OAuth 2.0 (expo-auth-session + PKCE)
- Persistent login with expo-secure-store
- Automatic token refresh (5 min before expiry)
- Auth guard for protected routes
- Gemini AI agent with full agentic tool-calling loop
- Gemini Vision — image and video frame analysis
- YouTube Data API v3 search tool (baked in, on by default)
- Google Custom Search tool (baked in, off by default)
- Save / retrieve items from local SQLite database
- Camera recording + photo capture
- Gallery picker
- Video frame extraction for Gemini Vision
- Chat UI with tool activity indicators and YouTube video cards
- Bottom tab navigation (Chat, Camera, Library, Settings)
- Feature flags system — toggle any feature in one file
- Typed, validated environment config
- Full TypeScript (strict mode)
- Docs: README, AGENT_INSTRUCTIONS, CUSTOMISE, ADD_A_TOOL
